# Николь · История моих чувств

Приватный сайт-письмо, созданный для Николь.

## Структура

- `index.html` — разметка страницы
- `css/style.css` — все стили
- `js/` — скрипты по модулям:
  - `lock-preloader.js` — экран блокировки и прелоадер с конвертом
  - `background.js` — пыль, сердечки, свечение курсора
  - `nav-music.js` — навигация и генеративная музыка
  - `timers.js` — таймер дружбы и обратный отсчёт
  - `reveal.js` — анимации появления, прогресс чтения, параллакс, активная глава
  - `carousel.js` — карусель фотографий
  - `achievements.js` — система достижений
  - `i18n.js` — переключение языка RU/EN
  - `typewriter.js` — посимвольное появление текста писем
  - `quote-letters.js` — плавное появление букв в цитатах
  - `secret.js` — секретная страница по тройному клику на сердце
  - `lightbox.js` — увеличение фотографий

## Публикация на GitHub Pages

1. Залей все файлы в репозиторий.
2. Settings → Pages → Source: `main` / `root`.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
